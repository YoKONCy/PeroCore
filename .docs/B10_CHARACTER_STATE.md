# 角色状态与桌宠表现

## 状态来源

`pet_states` 是角色三状态的持久来源：`update_state` 与 `finish_task` 写入，ContextCompiler、角色状态 API 和桌宠读取。提示词不再读取 ConfigRepo 内旧的 `agent.<id>.mood/vibe/mind`。未创建状态时共用 `DEFAULT_CHARACTER_STATE` 默认值。

- `mood`：角色的情感底色。
- `vibe`：当下外在表现。
- `mind`：简短角色心声，不承担任务计划、推理过程或系统信息。

任务执行、等待回答、录音与播报等继续使用已有运行状态，不推导为角色心情。

## 更新规则

三个字段独立可选，空白表示保留已有值；只提交有变化的相关项。状态工具与持久化入口共用去除首尾空白的规则。重复值不刷新状态时间，也不重复广播；状态未变化时工具成功返回 `updated: false`。完成任务时可通过 `finish_task` 顺带更新。

提示词说明这些是上次记录的状态，要求结合当前交流维持连贯，不要求每轮更新，也不按离线时长推演情绪。动态台词继续使用原来的追加、去重与六小时有效期。

## 模型表现

`Pet3DView` 将当前角色的心情与外在表现传给 `BedrockAvatar`，以少量明确词语匹配自然、明快、低落、担心、认真、害羞预设；不读取角色心声猜测情绪。未知、否定或混合描述回退自然待机，原始状态文字不变。

- 表现切换去抖 650ms，最短停留 2.2 秒，逐帧平滑过渡；不延迟文字更新。
- 只在现有支持骨骼上叠加小幅眼皮、眉毛和头部姿态，保留模型自身眨眼与动画。
- 拖拽、触摸和手动动画优先；角色或模型切换重置表现缓存，组件卸载清理计时器。
- 缺失对应骨骼时跳过该部分。没有添加常驻 HUD、模型资源、情绪数值或额外模型调用，表现层不会回写持久状态。
