# 国际化

支持 `zh-CN`（简体中文）、`zh-TW`（繁體中文）、`en-US`（English）。系统设定中的语言配置保存到服务端 `user.language`，浏览器缓存只用于启动时减少闪烁。语言切换不重建会话、不清空编辑内容。

## 分类词库

资源位于 `packages/shared/src/i18n/locales/<语言>/`，按用途与模块拆分，不能合并成一个总 JSON：

- `ui/`：主应用导航、聊天、设置、工具、工作区及其他界面组件。
- `logs/`：服务端各模块与前端日志。
- `server/`：API 返回文案与服务界面元数据。
- `electron/`：窗口、托盘、原生服务及相关日志。
- `apps/arca/`、`apps/pictoria/`、`apps/social/`：子应用界面与日志。
- `errors/`：应用自带的异常提示，按运行端分别维护。
- `common/`：跨端共用的工具名称、界面选项与提示词组件显示名称。
- `platform/`：独立能力节点的终端输出。
- `scripts/`：开发启动、构建、版本同步等脚本的终端提示；通过 `INFOS_LANGUAGE` 选择语言。

`catalogs/` 中的 TypeScript 文件只装配各运行端需要的词库。共享翻译运行时不依赖 Vue、Electron、网络服务或 OpenCC。简中原文作为分类内的稳定查询键；同一句话在不同模块可以有不同翻译。

## 使用

```ts
import { t } from './i18n'
t('ui.chat', '加入队列')
t('logs.agent', '正在执行 {0}', [toolName])
```

动态值通过 `{0}`、`{1}` 插值。先翻译模板，再原样插入参数；不拼接完整动态字符串后做模糊替换。Vue 模板和计算属性中的翻译会追踪语言变化；静态选项使用 getter，避免语言切换后仍保留旧标题。

词库查找顺序为当前语言、同模块简中原文、调用处原文。未知语言回退简中；`zh-HK`、`zh-Hant` 归到繁中，其他英语区域归到 `en-US`。

## 同步与启动

- 主应用完成鉴权后恢复服务端语言；同源窗口通过浏览器存储事件同步。
- 配置单项、批量写入、导入、删除都会更新服务端语言。Gateway 将语言变化同步到在线客户端。
- Electron 缓存本机语言，向托盘、主应用、通知层和内置子应用广播变化；内置子应用只能读取语言，不能修改全局设置。
- 独立子应用使用自身浏览器语言缓存，不依赖 infOS 服务。独立 Node 进程可以使用 `INFOS_LANGUAGE=zh-TW` 或 `INFOS_LANGUAGE=en-US`；服务端启动后以已保存配置为准。
- 启动到数据库配置恢复之前的日志使用环境语言。历史日志不回写，后续日志使用新语言。
- 开发启动器使用固定就绪标记，不解析已翻译的日志句子；终端颜色控制符不进入词库。

## 保持不变的内容

用户消息、Agent 回复、角色人设、提示词正文、用户自定义名称、工作区路径、模型 ID、协议字段与第三方原始输出不属于界面词库。不得通过 DOM 全页替换或任意字符串替换来翻译这些内容。

内部异常原文和错误码保持不变，防止影响重试与恢复判断；只在 API 错误返回或界面展示边界匹配项目登记的错误模板。工具函数名与模型可见协议保持不变，用户显示名称单独翻译。

## 译文维护

本轮为存量文案生成了三语言初始词库。繁中采用词组级转换，英文为初译并统一了部分高频术语，后续可以直接在对应分类 JSON 中润色，不需要修改业务代码。开发期间使用的提取、迁移和初译脚本位于 `TEMP/`；应用运行与构建不调用翻译服务，也不依赖这些临时脚本。

修改模板时同时维护三种语言，并保留相同的插值编号。运行时回退用于兼容缺失条目，不代表缺失译文已经完成。回归用例位于 `packages/shared/tests/i18n.test.ts`；本次未运行构建、测试、类型检查或 ESLint。
