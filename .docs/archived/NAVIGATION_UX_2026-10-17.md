# 页面切换 UX 收尾 · 2026-10-17

## 已实现

- 主导航切换使用滑动选中底板、短距离退场和入场；模块加载与动画并行，不人为延迟页面提交。
- 角色、Thread、工作区文件、据点房间切换接入统一过渡。会话输入框保留挂载，切换期间暂停发送。
- 加载占位延后 100ms 显现，避免短请求闪一下占位。占位退出没有额外等待。
- 外层整页过渡时抑制内层淡入，避免透明度叠加和连续两次入场。
- 连续主导航点击只提交最后的目标；点回当前页会取消未完成的切换。过期动画回调不能清理新动画。
- 导航高亮观察各个项目的尺寸和文字变化，适配标题更新、标签增删、侧栏折叠及窗口缩放。
- 角色切换期间隔离旧会话列表操作；角色变化立即清空旧列表，标题随会话列表与当前 Thread 同步。已有列表刷新时不插入加载行，避免列表上下跳动。
- 会话与角色列表支持键盘操作和可见焦点，主导航标注当前页面与加载状态。
- 审批、网络恢复引发的后台刷新不抢占用户导航，也不向其他角色的会话发起刷新。角色切换期间到来的外部会话定位在角色切换结束后继续处理。
- 关闭或删除正在加载的文件会结束对应遮罩，过期读取不再获得焦点。
- 完整、减少、关闭动效偏好与系统减少动态效果兼容；运行途中减少动效会取消旧位移。
- Electron 自有子应用在自己的渲染层淡入，主进程控制可见性；任意外部网页不注入此动效。

## 自定义背景兼容

页面材质选择器不再依赖 `.main-content` 与页面根节点的直接父子关系。对话、工作区、据点、角色管理、社交配置、系统终端继续继承自定义背景设置。

背景启用时过渡不动画整块内容的透明度，也不保留 `will-change: opacity`，避免影响子面板的透景。加载占位使用相同的背景材质变量。

已通过源码审阅及以下静态检查：

- infOS 前端 `vue-tsc --noEmit` 与 155 个组件的模板语法检查。
- Electron `tsc --noEmit -p electron/tsconfig.json`。
- 测试源码 `tsc --noEmit -p tsconfig.test.json`。

补充了导航被后台刷新打断、旧请求迟到、动画被中断、内外层过渡协调、自定义背景兼容及运行中切换动效偏好的回归用例。根据项目约定，本轮没有运行构建、测试套件或应用，不将类型检查当作运行时交互验收。

## 尚未执行的运行时复查

1. 冷启动切换主导航，连续点多个页面，再点回当前页，检查最终页面与高亮一致。
2. 快速切换已有 Thread，刷新历史列表，检查占位闪烁、列表位移和标题同步。
3. 切换角色期间触发审批变化、网络恢复或外部会话定位，检查最终会话归属、输入草稿与发送状态。
4. 开关自定义背景，切换六个受材质控制的页面，检查透景和浅色、深色主题。
5. 加载文件期间关闭或删除文件，检查遮罩退出与最终编辑页。
6. 切换原生子应用、增删标签、调整窗口大小与导航宽度，检查高亮位置和子应用呈现。
7. 动画途中切换减少或关闭动效，最小化再恢复，检查停止与恢复行为。

未实测 FPS、延迟或内存降幅；动画不能消除同步长任务本身，性能部分参见同目录的性能优化记录。
