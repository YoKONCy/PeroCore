# 界面性能优化记录 · 2026-10-17

## 已实现

| 场景               | 修改                                                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 长思考、长回复     | 每个节点持有增量分段游标，只扫描新增完整行；稳定段落复用对象。兼容源码替换、围栏、HTML、CRLF 和块公式内部空行。                              |
| 流式尾部           | 未稳定内容用纯文本追加，文本节点按约 2K 字符拆分，避免逐帧执行 Markdown、公式、高亮与 DOMPurify，并尽量保留已有选区。稳定后恢复完整富文本。  |
| 富文本加载         | 解析器按需导入；稳定内容经共享队列分批解析，每批检查 4ms 预算并让出执行权。单次解析不可抢占，此预算不是单任务耗时上限。                      |
| 富文本缓存         | 只缓存稳定版本；同时限制条目数和源码、HTML 总字符数。超过 32K 字符的代码块保持代码格式与复制功能，跳过语法高亮。                             |
| 折叠、隐藏与恢复   | 折叠思考不挂载解析组件；不可见消息暂停解析、动画与媒体。KeepAlive 恢复后重新观察原消息，忽略旧观察器回调；图表恢复时复用已有 SVG。           |
| 流式合成           | 批次内共用私有节点数组与操作去重集合，发布前的旧快照保持不可变。隐藏时合并增量，队列设上限，提交、失败终态仍立即合成。                       |
| 桌面外壳           | 富文本变化不再引发全局弹窗扫描和原生视图边界测量；跟踪实际弹窗，独立处理边界变化。                                                           |
| 最小化与子应用标签 | 主界面合并原生窗口可见性、Page Visibility 和桌面标签状态；子应用 WebContents 启用后台节流。后台任务继续由子应用后台执行。                    |
| 冷启动与切屏       | 角色请求共用在途结果，聊天正文不再等待侧栏历史列表；已加载会话直接复用。首屏完成后在空闲时逐个预热工作区与据点。                             |
| 工作区文件         | 切回时优先校验当前文件，其他文件切换到时再校验；版本未变的文本不重复读取，保留未保存缓冲。                                                   |
| 滚动阅读           | 内容尺寸变化合并吸底；用户上翻立即解除吸底，选择文字时暂停跟随。加载历史以原消息为锚点，避免将回复尾部增长计入新增历史高度。                 |
| 据点               | 复用未变消息适配结果；隐藏时暂停轮询，可见后同步，避免轮询重叠；复用聊天滚动与可见性管理。                                                   |
| Arca               | 编辑只复制一个候选稿；撤销栈共享不可变快照，复用未变的基础版本、正文和在途请求序列化。仍然每次编辑立即保存本地草稿，保留重试事务和冲突处理。 |
| Pictoria           | 节点拖动时暂停深度保存观察器，手势结束后合并处理；去除重复未保存通知，隐藏时跳过状态轮询并在可见后同步。                                     |
| 性能诊断           | 接通长任务观察，定期采样内存；每项仅保留最近 2048 个样本，帧字节大小每 32 帧抽样一次。                                                       |

## 回归覆盖

补充了增量分段、围栏和公式完整性、纯文本追加与 HTML 安全、旧快照不可变、帧去重、隐藏合成、可见性恢复、会话复用、草稿立即恢复和性能样本窗口的回归用例。

本轮按项目约定未运行构建、测试套件或应用，不将源码审阅与类型检查当作运行性能验收。

已通过的静态检查：

- infOS 前端 `vue-tsc --noEmit` 与 154 个组件模板检查。
- Arca 客户端 `vue-tsc --noEmit` 与 19 个组件模板检查，包含客户端测试源码的类型检查。
- Pictoria 客户端 `vue-tsc --noEmit` 与 26 个组件模板检查。
- 根测试源码、共享包、Electron 的 `tsc --noEmit`。

## 运行时复查

开发模式控制台可调用 `window.__INFOS_PERFORMANCE__()` 查看滚动窗口统计：`main_thread_long_task_ms`、`rich_text_render_ms`、`surface_flush_cpu_ms`、`surface_frame_to_flush_ms`、`surface_flush_batch_frames`、`js_heap_used_bytes`。其中帧字节指标是抽样分布，不代表总流量。

建议在同一台机器、相同会话和相同窗口大小下复查：

1. 冷启动后切换对话、工作区、据点，再切回；检查正文是否被侧栏请求阻塞。
2. 长思考与长回复输出时持续上翻、选择文字、折叠与展开；检查选区、滚动位置、最终公式及代码。
3. 生成中切换子应用标签、最小化再恢复；检查正文是否追上最新状态，停止、审批与错误是否正常。
4. 加载多页历史期间继续生成；检查历史锚点和回到底部操作。
5. 大文稿连续输入、撤销、保存期间继续输入、关闭再打开；检查草稿与回执。
6. 大画布连续拖动、缩放、切换页面和关闭标签；检查最终坐标、未保存提示及后台任务继续执行。

## 边界

保留分页历史和真实 DOM 高度，没有重新引入曾造成大块空白的高度固化方案。极大量历史 DOM 和单个超大富文本任务仍可能产生开销，需要运行时性能轨迹确定下一步。

本轮没有改变模型输出、工具执行、Token 预算与精确计数规则，也没有实测 FPS、延迟降幅或内存降幅。
