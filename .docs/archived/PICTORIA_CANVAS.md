# Pictoria 自由画布第一版

## 退出应用

- 画布和工作流右上角的电源图标打开「退出 Pictoria」确认框，适配深浅色并带淡入淡出过渡。
- 「保存并退出」先暂停页面轮询与自动保存，完成当前画布和工作流的最终保存，再停止后台。保存或退出失败时保留页面并显示原因；上传、提交和切换期间不能退出。
- infOS 托管模式停止后台后自动关闭 Pictoria 标签页，infOS 继续运行；普通关闭标签页仍只关闭界面。重新打开 Pictoria 可以重新启动后台。
- 独立模式使用 Pictoria 自身的本机会话退出，不依赖 infOS。浏览器不允许自动关闭的页面显示「已退出」；运行记录由原有持久化与恢复机制保留，远程任务的提交状态仍需恢复时核验。
- 外部自行启动、由 infOS 接入的实例由原启动位置管理，不通过托管退出接口结束。

本轮仅人工审阅源码，未运行构建、测试、类型／静态检查或界面调试。

## 界面结构

画布占据整个子应用页面。顶部只保留项目与保存状态，左侧浮动选择／平移／导入／便签／撤销工具，右下角缩放与适应视图。选中内容后就近显示操作栏；底部创作栏承接文字与所选素材。

不沿用主应用的像素边框与字体。暗色采用炭灰底、淡紫强调色；浅色使用暖白底与低饱和紫色。图标、品牌标志与空状态插图使用内置 SVG，无远程字体或图片依赖。入场、菜单、任务等待使用轻动效，并尊重系统减少动态效果设置。

## 文件与职责

- `packages/apps/pictoria/client/src/App.vue`：画布外壳、项目／素材／设置浮层。
- `composables/useCanvasNavigation.ts`：坐标转换、按帧拖动、缩放、框选、快捷键。
- `composables/useCanvas.ts`：项目、草稿、版本保存、撤销、素材生命周期、任务恢复。
- `components/CreationBar.vue`：步骤选择、作者说明、schema 输入、素材引用与幂等提交。
- `components/CanvasCard.vue`：素材、便签、任务三类内容。
- `services/transport.ts`：客户端兼容层，访问固定的 infOS 画布控制接口。
- `electron/main/services/pictoriaSurface.ts`：仅允许 Pictoria 页面调用自身受限接口，API 令牌保留在主进程。

## 接入与保存

Manifest 声明 `main.tab` Surface；Electron 注册自身 URL 边界与嵌入 Preload。启动入口与 Arca 一样从应用控制面解析，开发界面默认 7363，发行界面为 `/applications/pictoria/`。

`pnpm start` 负责启动 Pictoria 界面开发服务，在其监听 7363 后才开启 Electron。后台直接通过 `--import` 注册 tsx 加载器，避免 CLI 派生进程导致发现记录 PID 不一致、启动后被误判超时。后台启动失败会返回明确的服务不可用错误，入口不会吞掉异常继续打开失败标签。

项目使用 `{id,title,items:[{id,content,x,y}],edges?:[...]}` 契约。内容的视觉尺寸和种类保存在 `content` 内，保存携带 `expectedRevision`。旧调用省略 edges 时保留仍有效的引用。与 Agent 同时编辑发生版本冲突时停止自动写入，保留本地草稿，并可另存副本。

素材上传经宿主代理到 Pictoria 的私有 HTTP 接口，预览校验所有权与 SHA-256，不向页面暴露桥接密钥。画布手动提交使用独立 `app_internal` Thread 记录宿主交付；Agent 工具仍回传它原来的聊天。

## 画布创作与资源库迭代（2026-10-14）

- 默认自由操作：空白处左拖平移，卡片左拖移动；Shift＋左键拖动追加框选，Shift 单击多选；V 切到框选，A 返回自由操作，H 切到平移。
- 选中或悬停素材／便签可见输出点；拖到创作草稿的输入点建立引用。图片、文字与数量在连接时检查，提交前由 JSON schema 再次校验。
- 素材和便签同时提供右侧、底部输出点，步骤卡同时提供左侧和顶部输入点；方向随连线保存。下方创作栏提供独立连接入口，接入图片时可切到兼容的编辑步骤，引用线跟随平移、缩放和输入栏尺寸变化。
- 创作栏与步骤卡共用参考素材控件，显示缩略图、编号与数量上限；连接第一份素材后仍可继续添加，支持逐项前后排序、移除。固定引用与连线引用合并校验，按照显示顺序提交真实素材数组，当前内置编辑步骤最多 10 张图片。
- 创作栏引用独立于画布选中状态，切换选中内容不清空已经添加的参考；切换画布或角色则重置。批量导入会按导入顺序选中全部成功素材，创建草稿时保留输入次序和连线方向。
- 创作栏的“加入画布”允许保留不完整草稿；草稿中编辑参数、排序参考图、断开引用、更新步骤版本，然后点“生成”。直接“开始创作”也会留下草稿。
- 可编辑引用与历史来源区分显示；提交保存输入、步骤与来源快照。已完成任务不随草稿改写。网络中断保留原幂等键，未核验的提交不自动重复计费。
- 一键整理按关联关系从输入排到输出，孤立内容按类型排列；可整理选中内容或整个画布。位置按帧过渡，连线随实际位置更新，一次撤销即可恢复。
- 浅色使用清晰的白色浮层、柔和紫色选中态；背景低强度呼吸光与连接反馈尊重减少动态效果，后台停止装饰背景动画。
- 资源库分为素材、成品、提示词三页，搜索和分页在后台执行。素材支持预览、标签、名称、收藏、下载与拖入画布。生成／编辑结果自动归档，可标记最终稿、查看生成参数和再次编辑。升级前的历史成功输出会补建索引。
- 提示词支持新增、编辑、删除、标签及适用说明，原样填入创作栏或作为便签加入画布；不自动转换自然语言与 tags。
- 删除画布卡片只删除摆放实例与关联线，不删除后台文件；文件继续按角色归属隔离。

## AtlasCloud 内置步骤

画布设置中填写 AtlasCloud API Key，为图像生成和图像编辑分别选择 Nano Banana Pro 或 Seedream 5.0 Pro。凭据使用已有加密 Secret 存储，客户端只读取配置状态。两个步骤在凭据完整时可调用；模型变化更新 schema、使用说明和步骤版本，已排队任务保留原版本。

适配器负责素材上传、异步生成、轮询、旧结果接口兼容及结果落盘。当前编辑输入接受每张 20 MB 以内的 PNG／JPEG／WebP，最多 10 张；画布仍可浏览 GIF、视频、音频。供应商没有远程取消端点，现有取消操作只停止本地等待。

接口依据：

- [AtlasCloud 上传文件](https://www.atlascloud.ai/docs/upload-files)
- [Nano Banana Pro 生成](https://www.atlascloud.ai/docs/en/more-models/google/nano-banana-pro-text-to-image/generateImage)
- [Nano Banana Pro 编辑](https://www.atlascloud.ai/docs/more-models/google/nano-banana-pro-edit/generateImage)
- [Seedream 5.0 Pro 生成](https://www.atlascloud.ai/docs/ja/more-models/bytedance/seedream-v5.0-pro-text-to-image/generateImage)
- [Seedream 5.0 Pro 编辑](https://www.atlascloud.ai/docs/zh/more-models/bytedance/seedream-v5.0-pro-edit/generateImage)

## 项目层级与交互精简（2026-10-14）

- UI 增加可选的“项目 → 画布”分组；未分配项目的画布显示在“独立画布”。项目可新建、重命名、移除，画布可在项目之间移动。移除项目仅解除归属，保留画布、素材和任务。
- 为兼容已有接口，底层 `project` 实体继续表示画布；外层项目使用 `collection` 实体和 `collection.list/save/delete` 操作，画布通过可空 `collectionId` 关联。新增 `project.move` 专门修改归属，旧 `project.save` 省略此字段时保留已有归属。分组和移动均校验角色所有权与版本。
- 画布草稿、自动保存、撤销重做和另存副本包含归属信息；分组移除与自动保存串行衔接，遇到并发编辑保留本地修改，不覆盖远端新版本。
- 步骤菜单只显示“模型名 · 用途”，移除说明段落与重复提示。作者的 `usageDescription` 仍保留在后台契约中，供 Agent 理解步骤要求。
- 所有选择框统一为带过渡的自定义浮层，支持键盘操作、自动向上展开和视口边界调整；菜单脱离滚动容器，避免被面板裁切。输入框补齐焦点与悬停反馈，常用文字小幅放大。
- 深浅色切换使用渐隐渐显，支持时使用浏览器视图过渡，其他环境使用颜色过渡；尊重减少动态效果。浅色画布采用暖白纸面、稀疏细纹与柔和环境光。
- 手形模式、空格和中键在捕获阶段接管平移，不移动或缩放节点，不触发节点编辑、连接操作。Shift＋左键在空白处或节点上均可追加框选，优先于手形模式；空格和中键仍优先平移。Shift 单击切换单个节点的选中状态，输入框内保留文字选择行为。
