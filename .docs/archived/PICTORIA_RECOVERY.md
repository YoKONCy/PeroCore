# Pictoria 请求与恢复规则

更新日期：2026-10-14。本轮仅人工审阅源码，未执行构建、测试、静态检查、应用启动、断网／崩溃演练或真实提供商调用。

## 保存顺序

1. 画布保存输入和稳定请求键，子应用将接受的任务写入 SQLite，再交给后台执行。
2. 发送提供商请求前，持久化请求指纹、凭据摘要与 `prepared` 记录；节点进入执行和请求进入 `sending` 在同一事务内完成。记录保存失败时不发送请求。
3. 收到响应后保存 `received` 回执，再推进节点。回执包含提供商响应，保存在子应用私有数据库，不随任务快照发送到客户端。
4. 图片逐份下载；临时文件写入并同步后原子改名，再保存素材与资源回执。已保存的输出逐份记入节点检查点，恢复前核对文件大小和 SHA-256。
5. SQLite 使用 WAL 与 `synchronous=FULL`。数据库保存异常会暂停派发新请求，等待恢复；同批请求中止后等待全部退出，避免旧请求尚未结束就重新启动任务。

## 自动恢复与人工核验

| 阶段／结果 | 恢复行为 |
| --- | --- |
| 明确尚未建立连接、DNS 暂时失败 | 保留原任务，退避后重试 |
| 供应商明确拒绝且可以稍后重试，例如 HTTP 429 | 遵守 `Retry-After`，退避重试 |
| HTTP 5xx、超时或断线，无法确认生成请求是否已接受 | 进入 `waiting`／`uncertain`，保留记录，不盲目重新生成 |
| 已保存远程任务 ID | 断线和重启后继续查询，不重新提交生成 |
| 已有提交回执但节点尚未推进 | 从回执恢复远程 ID，或恢复同步响应的保存阶段 |
| 已生成、下载暂时失败 | 继续保存输出，复用已完成且校验通过的文件；未完成文件重新下载 |
| 远程下载地址过期 | 保留已保存资源，重新查询原远程任务以取得结果地址 |
| 自动恢复窗口结束 | 保留远程 ID、响应和成功输出，可在任务卡继续恢复 |

可安全重试的单次网络操作最多立即尝试 3 次；后台继续使用持久化退避时间与次数调度，默认恢复窗口为 6 小时。取消任务会停止本地重试；未配置远程取消接口时不承诺供应商停止执行或停止计费。

AtlasCloud 编辑输入的上传回执按任务、输入序号和素材 ID 分开缓存，短期复用上传地址。上传与生成使用不同请求身份。AtlasCloud 未在本适配器声明生成幂等支持，因此未知提交结果始终需要核验。

任务卡提供“恢复任务”：

- 有远程 ID 时继续查询原任务。
- 提交结果未知时，可填写供应商任务 ID，再继续查询。
- 只有单独勾选“已核验，需要重新提交”后才增加尝试编号，创建新的生成请求；这可能再次计费。
- 多个提交不确定的分支需要逐个核验；未核验完成时不启动后续分支。

本地记录无法消除“供应商已接受、但响应和远程 ID 都未到达本机”的分布式不确定性，不能宣称任何断电或网络条件下都能自动查回任务、恰好生成一次或绝不重复收费。

## 通用 API 服务配置

AtlasCloud 与作者自定义的 JSON／multipart／同步／异步服务共用请求回执、超时、退避、响应大小限制、资源落盘与恢复机制。

| 字段 | 含义 |
| --- | --- |
| `timeoutMs` | 原有节点执行期限 |
| `requestTimeoutMs` | 可选，单个 HTTP 请求超时；AtlasCloud 新配置为 90 秒 |
| `recoveryWindowMs` | 可选，可恢复阶段的自动重试窗口；默认 6 小时 |
| `idempotencyHeader` | 可选，供应商明确支持的幂等请求头 |
| `idempotencyWindowMs` | 可选，供应商保证幂等生效的时间窗口 |

只有同时配置真实支持的幂等头与有效窗口、请求内容和凭据均未变化，才允许自动重放提交不明的生成请求。不能仅因设置了一个任意请求头，就假定服务端会去重。窗口过期后继续保留任务供核验。

通用请求单次上传／请求指纹上限 100 MB；响应 JSON 上限 24 MB、二进制上限 100 MB。资源输出顺序保存，避免同时下载大量大文件。生成请求即使用 GET 也不会因此视为可无条件重试的读取操作。LLM 桥接未声明幂等能力，调用结果不确定时继续采用保守核验策略。

## 节点备注与搜索

- 根素材、文字、步骤草稿和任务卡均有可选备注，悬停或选中后点备注图标编辑；空备注不要求填写。
- 备注随画布保存，包含在本地草稿、撤销／重做和副本中，不混入绘图提示词或生成服务输入。
- 左侧常驻搜索支持备注、提示词、文字便签和文字输入引用；生成素材保留提示词索引。
- 输入后平滑定位并高亮首个匹配。多个结果可点上一项／下一项循环跳转，也支持 Enter／Shift+Enter、F3／Shift+F3；Ctrl+F 打开，Escape 关闭。
- 搜索跳转只调整视野和搜索高亮，不修改画布选中项或创作栏参考图。屏幕外的当前匹配也会挂载，避免定位到空白。

## 删除与任务恢复

- 主动删除任务卡时，画布持久化 `dismissedRunIds`；本地草稿、后台保存、导出与撤销／重做均包含此记录。重新打开和幂等提交回执不会再自动补回该任务卡。
- 自动恢复只补回未被移除的进行中任务，不再把已完成、失败或取消的历史任务重新铺到画布。任务记录和图库资源仍然保留。
- 任务轮询及素材读取返回后检查原卡片是否仍存在，防止删除期间的异步响应再次创建输出节点。
- 画布与工作流删除节点后立即保存本地草稿，远端继续按自动保存机制写入。
