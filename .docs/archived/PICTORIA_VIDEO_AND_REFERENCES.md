# 视频步骤、资源引用与纵向工作流

## 视频生成

供应商设置增加「视频模型」。已有供应商配置打开后保存一次，会创建独立的视频生成步骤；画布与工作流共享这些步骤。视频只提供统一入口，参考图片可选，不区分文生和图生。

| 供应商 | 首批型号 | 参考图片 |
| --- | --- | --- |
| AtlasCloud | Wan 2.6 | 可选 1 张；自动选择对应生成接口 |
| APIModels | Grok Video 3、Grok Video 3 固定计价 | 可选最多 7 张 |
| APIModels | Veo 3.1、Fast 1080p、Fast 720p | 可选最多 2 张；顺序为首帧、尾帧 |

模型字段分别声明，不把时长、分辨率套用到所有型号。Veo 固定 8 秒，分辨率由型号决定，不暴露无效参数；Grok 按文档中参数表限制档位。Wan 无参考时将比例与分辨率映射为官方支持的具体尺寸，有参考时按参考图构图。

参考图接受 PNG／JPEG／WebP，每张最多 10 MB。AtlasCloud 使用原上传 API；APIModels 使用官方签名 PUT：申请地址需要平台认证，上传文件到 R2 不携带平台 Key，不接受跨域重定向。上传完成 URL 单独持久化；短期签名过期可重新申请，已经提交的生成请求仍服从回执与不确定提交保护。

视频输出通过通用资源落盘与素材卡预览，不作为图片强制解码。供应商注册表与凭据归属同图片步骤，独立运行同样可用。工作流节点目录另外提供「视频 API」起点，带可选参考图和视频输出 schema；可复制已配置的视频 API 或填写自己的接口。

文档来源：[AtlasCloud Wan 图生接口](https://www.atlascloud.ai/docs/en/more-models/alibaba/wan-2.6-image-to-video/generateVideo)、[Wan 文生接口](https://www.atlascloud.ai/docs/en/more-models/alibaba/wan-2.6-text-to-video/generateVideo)、[APIModels Grok](https://apimodels.app/zh/docs/grok-video)、[Veo](https://apimodels.app/zh/docs/google-veo)、[文件上传](https://apimodels.app/zh/docs/files)。

## 模型与素材选择

- 步骤目录、模型下拉和节点标题显示供应商、模型和用途；目录搜索包含供应商名。读取旧版本步骤时同样补齐展示信息。
- 画布节点、下方创作栏、工作流固定输入及试运行输入均可打开「资源库」。
- 资源库按当前创作归属查询，可切换素材／成品，搜索名称与资源信息，分页加载；按字段识别图片／视频／音频类型。
- 选取资源直接保存素材 ID 引用，不要求先放到画布，不创建虚假的画布连线；多参考保留顺序、去重与数量限制。删除引用不删除资源文件。

## 凭据隔离

- 同源不能直接认定为同供应商：复用 Key 同时校验适配器、认证 Header 和前缀。
- 内置供应商密钥绑定各自官方域名及适配器；复制节点时声明原服务 ID，后台验证凭据来源。
- 显式输入新 Key 时强制绑定到新服务自己的密钥槽，移除旧别名。
- 通用服务／供应商修改域名或认证时，必须输入新 Key 或明确移除旧凭据，不能静默保留。
- 独立服务新增凭据范围记录；旧任务快照与当前共享供应商不匹配时阻止发送，避免把新 Key 发给旧域名。
- 前端切换供应商、适配器或认证配置会清空尚未保存的 Key；无效旧配置仍可打开编辑，目录不会整体报错。

## 工作流布局

默认连线由底部输出到顶部输入，每个字段都有独立连接点。保留显式侧面连接；「整理」会统一为纵向连线。

整理按依赖划分纵向层级，同层分支横向分列并按父节点位置排序，预留节点高度和附属备注空间。新节点默认加在选中／末尾节点下方；新建及示例工作流从上到下排布。已有手动布局不会在打开时被强行改写，可点「整理」转换。动画与撤销继续保留。
