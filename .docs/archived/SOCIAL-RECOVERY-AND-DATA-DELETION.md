# 社交恢复与数据清理

## 社交任务

- 明确触发的入站消息与待处理标识同事务保存。每个会话内存最多缓冲 100 条，每批处理 10 条，其余由持久队列补入。
- 直接回复、自主观察、延后意图和主 Agent 委派共用 `SocialBridge` 的执行现场。批次重试保持原消息集合，新消息进入下一批。
- 默认整轮期限 360 分钟；模型无数据超时 10 分钟、单次请求总上限 30 分钟；自动重试总预算最多 2 次。以上可在社交设置调整。
- 排队和执行共享取消信号；LLM、重试等待、NapCat 请求和分段发送均响应取消。手动取消、关闭会话、暂停应用和角色策略切换后，不自动重放已取消任务。
- 检查点保存完整模型回合、工具游标和分段发送标识。重启后跳过已完成工具和已确认发送；执行或发送结果不明时进入“执行结果未确认”，停止自动重放。
- 输入预算包含工具定义和真实协议开销，优先缩减历史及大工具结果。当前请求和框架指令保留；上游上下文超限后再缩减一次。输出截断反馈给 Agent，最多续写两次，截断的工具参数不会执行。
- 终态删除检查点中的上下文正文和图片，只保存标识、结果及错误摘要。任务中心与社交设置读取持久状态；错误可标记“已处理”，不会在每次启动时重新弹出通知。
- 社交记忆先检查门槛再进入统一执行器，避免每条消息都创建一个空的后台任务。

## 操作范围

| 操作 | 清理范围 | 保留范围 |
| --- | --- | --- |
| 记忆归档 | 退出主列表和默认召回 | 正文、历史与关系；归档页可恢复 |
| 永久删除记忆 | 当前版本及修订链、关系、操作副本、索引、相关日期的生成日记、检索学习状态 | 来源对话及工作区原文件 |
| 同时删除来源对话 | 再清理对应消息、附件文件、摘要、日志、文件变更快照及该会话的计划、心流副本 | 工作区文件；不执行文件回滚 |
| 撤回事实 | 退出有效事实 | 历史记录 |
| 永久删除事实 | 正文、操作副本、向量与文本索引；清理无剩余事实的对象和别名 | 同一对象的其他事实 |
| 永久删除知识 | 原文、分段、摘要、向量、文本镜像与索引 | 导入时的外部原始文件 |
| 重置全部记忆 | 全部角色的事件记忆、共享事实、关系、索引、生成日记及检索学习状态；覆盖已移除角色的残留索引目录 | 对话、知识文档、角色配置和工作区原文件 |
| 同时遗忘社交长记忆 | 再清理社交长记忆、恢复现场及待处理标识；旧消息标记为已处理，防止再次炼化 | 社交消息与联系人印象 |
| 社交会话／全部消息清理 | 对应消息和任务恢复现场，取消对应在途任务；保留历史同步删除标记 | 已炼化的长记忆与联系人印象 |
| 社交长记忆清理 | 当前角色长记忆、索引、恢复现场和生成日记副本；阻止旧消息再次炼化 | 社交消息与联系人印象 |

永久删除范围是 infOS 管理的上述数据及派生文件；外部服务、导入源文件、用户备份和操作系统备份属于独立副本。已投递给外部平台的操作不能通过取消撤回。

## 删除账本

`privacy_deletions` 先登记目标与来源标识，再清理 SQLite、TDB、文本镜像及生成文件。来源只留标识或哈希，成功后清空任务元数据。查询、写入与事务重放统一检查删除标记；清理失败期间保持目标不可见，并暂停对应记忆写入。

进程重启恢复未完成清理；单个清理任务最多自动尝试 5 次，之后由“数据清理”面板手动重试。批量永久删除逐项登记，失败项进入恢复队列。SQLite 启用 `secure_delete`，删除完成前截断 WAL；TDB 关闭后删除受管文件并按剩余权威记录重建。

社交清理另有版本屏障，按角色与会话限制旧任务回写；联系人印象按目标保留删除时间。QQ 消息重放按账号与消息标识去重。

## 入口

- 记忆页：记忆／归档、恢复、永久删除、选择本页与批量操作。
- 知识库：撤回事实、永久删除事实与资料。
- 危险区域：重置全部记忆、是否同时遗忘社交长记忆。
- 任务中心／社交设置：社交任务状态、取消、已处理。
- 记忆、知识、社交清理和危险区域页面：待完成的数据清理与失败重试。
