# infOS 退出异常修复与全量验证

验证环境：Windows、Node.js 22.22.2、pnpm 9.15.9。

## 退出异常

截图中的异常来自 `DesktopToastLayer.dispose`：主窗口触发 `closed` 时，窗口原生对象已经销毁，清理函数再次读取 `host.webContents`，因此抛出 `Object has been destroyed`。

通知层现在提前保存主窗口与浮层的 WebContents 引用，解绑监听器不再读取已销毁窗口；发送、同步、加载回调也检查窗口、WebContents 和当前实例是否仍然有效。清理支持重复调用。

回归测试模拟了销毁后访问 `webContents` 会抛错的原生窗口，同时覆盖 WebContents 先于窗口销毁的顺序。

## Docker 与 CI/CD

- 前端镜像补入 PDF 构建插件；后端构建并携带 Arca、Pictoria 发行资源，设置发行目录，收集 Arca 运行依赖，并准备原生依赖构建工具。
- Nginx 补入子应用和 HTML 预览路由、WebSocket 升级、带端口的 Host 转发及 32 MB 请求限制。
- Arca 浏览器通过宿主公开端口连接，服务器内的回环地址不再用于远端浏览器连接；代理校验 Token、来源与回环目标，覆盖文本、二进制和断开清理测试。
- Docker 构建上下文及 ESLint 排除依赖缓存、生成产物和运行数据。
- CI 与发布统一使用 Node.js 22，最低版本说明更新为 22.13；补入全包类型门禁、Windows/Linux 测试矩阵及真实 Docker 构建、健康检查、子应用启动、握手与停止验收。
- Steam 构建显式禁止自动发布；预发布镜像不覆盖 `latest`；发行 Compose 使用当前仓库所有者并校验版本标签；Changelog 获取完整 Git 历史；Windows 重试清理验证目标路径。
