## 编辑与重新导出

母稿是细节保留优先的高密度颜色路径，人物没有拆为骨骼动画层。光轨、局部泛光、悬浮窗、品牌与等待条保留独立分组。字标是项目定稿路径；副标题为用户指定品牌文字。

修改母稿后，通过浏览器按 1569 × 1080 渲染透明 PNG；渲染前删除 `#waiting-indicator`，导出时保留透明通道。不要把进度条烘焙进静态图，也不要将 SVG 母稿加入安装包运行时。

本轮制作脚本保存在 `TEMP/startup-splash-implementation/export-artwork.mjs`；制作环境与人物抠图依赖只用于设计，不是 infOS 或安装包的依赖。原始轮次的位图与 SVG 仍留在 TEMP 中，正式交付以此归档和 `electron/splash/artwork.png` 为准。

## 生命周期

`app.whenReady` 后先绘制本地图片和进度动效，再扫描模型资产、启动或复用内置 Daemon。业务健康检查通过后创建隐藏 Launcher；收到目标主框架的 Vue 双帧握手后再次确认健康，完成等待条过渡并显示 Launcher，最后销毁开屏窗口。

窗口管理器的正常显窗、显窗超时、加载失败和既有窗口聚焦入口均遵守启动门控。二次启动和应用激活在过渡期间只聚焦开屏。启动失败保留开屏，提供本地化的重试、日志与退出入口；开屏资源本身失败时使用原生提示。退出取消未完成启动链并移除开屏监听，不允许迟到结果重新显窗。

标准安装版、Steam 版和便携版由基础 `extraResources` 清单携带相同本地开屏资源；预加载脚本单独编译，暴露的仅为开屏状态和有限操作。主应用浏览器及 Docker 入口不加载此过渡。
