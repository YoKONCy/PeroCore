# Pictoria 核心约定

- Pictoria 是可独立运行的完整子应用。画布、工作流、素材、供应商配置、凭据与 API 执行必须能够脱离 infOS 使用。
- infOS 只通过兼容层提供可选的嵌入、Agent 工具、模型桥接与聊天交付。不得把主应用的模型配置、认证或生命周期作为子应用主体运行的前提。
- 子应用主体不得导入 infOS 私有后端服务；共享 SDK／声明式协议可以使用。独立模式与挂载模式共用 Pictoria 的数据契约和执行引擎。
- 节点 API 的保存默认创建独立定义，避免修改其他节点。共享供应商配置需明确引用，凭据只存入 Pictoria 的加密存储。
- 新供应商通过目录、适配器和配置编辑器注册，避免在画布页面散落供应商专用逻辑。
- 构建、测试、静态检查及注释规范遵守根目录 AGENTS.md 和用户当前指令。
